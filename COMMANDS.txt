IPFighter Checker - Command Reference
======================================

LOCATION
--------
cd /home/admin/Projects/ipfighter-checker


TESTING (Optional)
------------------
# Test proxy parser functionality
python3 test_parser.py


SETUP (First Time Only)
-----------------------

Linux:
  ./scripts/setup_linux.sh

Windows:
  scripts\setup_windows.bat


RUN APPLICATION
---------------

Linux:
  ./scripts/run_linux.sh

Windows:
  scripts\run_windows.bat


ADVANCED OPTIONS
----------------

# Run with custom worker count (3-15 recommended)
./scripts/run_linux.sh --workers 10

# Show help
./scripts/run_linux.sh --help


TROUBLESHOOTING
---------------

# Fix permissions (Linux)
chmod +x scripts/*.sh test_parser.py

# Install Python (Ubuntu/Debian)
sudo apt update && sudo apt install python3 python3-venv python3-pip

# Reset virtual environment
rm -rf venv && ./scripts/setup_linux.sh

EXAMPLE PROXY FORMATS
---------------------

Format 1: host:port:username:password
us.922s5.net:6300:user-zone-custom:password123

Format 2: host:port
proxy.example.com:1080

Format 3: username:password@host:port
user:pass@proxy.com:5000
